Source: https://github.com/davidwickerhf/enso (extension/ is this add-on, helper/ the native app). Nothing is bundled or minified. This package is extension/ at the tag for this version, built by `node scripts/build-extension.mjs --channel listed`: it deletes the lines between `// <unlisted-only>` markers in pageagent.js and writes channel.js (CHANNEL = "listed").

Permissions:
- nativeMessaging: the add-on is the browser half of a local helper app ("enso", Node.js, for macOS, Linux and Windows), installed with `curl -fsSL https://enso.wicker.life/install.sh | bash` (macOS, Linux) or `irm https://enso.wicker.life/install.ps1 | iex` (Windows PowerShell). The helper runs Claude (through Claude Code or the user's Anthropic API key) and the user's tools; the add-on shows the chat, new tab and settings and carries out page actions for it.
- <all_urls>, tabs, webNavigation, webRequest, cookies: the user asks Claude about, or to act on, whatever page they're on. pageagent.js is injected on demand to read the page and click/type when asked. webRequest/webNavigation keep a per-tab network and console log in memory for the developer tools (no bodies). cookies: signed-in requests only on sites the user allowed; cookie values never reach the model.
- history, bookmarks, search: new-tab suggestions and history search. tabGroups, contextualIdentities: Zen spaces. menus, clipboardWrite, storage: context menu, copy, settings.

Dynamic code: none. No remote code, no eval, no new Function. The listed build doesn't include the developer tool that evaluates JavaScript; it exists only in the self-distributed build. page_query and page_inspect are fixed queries (a CSS selector goes to querySelectorAll; attributes, rects and computed styles come back), with no code evaluation.

Safety: banking, payment, password-manager, health, tax and government sites are never read or acted on (helper/config.json sensitiveHosts, copied in background.js). Irreversible actions always ask. No analytics or telemetry. Nothing is sent automatically by default: the only direct network request from the add-on is search suggestions from the default engine (Google or DuckDuckGo, no credentials) while typing in the new tab's box, off until the user turns it on in Settings. The helper's daily brief is also off until turned on.

Testing without the helper: open a new tab or the sidebar (Ctrl+E, or Cmd+E on macOS). Ensō shows a guided setup with the install command and continues by itself when the helper connects. To see the full UI with a mock helper: `cd extension && python3 -m http.server 8000`, then open http://127.0.0.1:8000/newtab.html or /sidebar.html (docs/development.md).
